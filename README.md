# EscalioTech — sitio web

Sitio estático inspirado en el diseño de la página mostrada de Base44.

## Archivos
- `index.html` — estructura de la página.
- `styles.css` — diseño, responsive y colores.
- `script.js` — WhatsApp, redes sociales, menú móvil y animaciones.

## Antes de publicar
Abre `script.js` y cambia:
- `whatsapp`
- `instagram`
- `facebook`
- `tiktok`

El número de WhatsApp debe ir con código de país, sin `+`, espacios ni guiones.

Ejemplo:
`523312345678`

## Publicación
Puedes subir los 3 archivos principales a un repositorio de GitHub y después importar ese repositorio en Vercel.
